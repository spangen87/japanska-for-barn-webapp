# Minnesknep, romaji-guide och övning för lika tecken – design

**Datum:** 2026-10-22
**Ärenden:** #13, #10 och en del av #15

## Beslut

| Fråga | Beslut |
|---|---|
| Romaji-guide (#10) | En egen sida, "Så läser du romaji", som nås från startsidan. Kort med knepiga ljud får också en tipsrad som länkar dit. |
| Minnesknep (#13) | Nya minnesknep för alla 92 grundtecken, plus övningen "Lika tecken" i Öva |
| Romaji i övningar | Döljs i ordövningen tills barnet har svarat |

## Så fungerar det

- **Minnesknep:** visas på varje teckenkort under rubriken "Minnesknep". De ersätter platshållartexten och de fem knep som redan finns.
- **Uttalstips:**
  - **Vilka kort:** kort vars romaji innehåller ett ljud som svenska barn läser fel, till exempel ki, gi, y, ji, z, r, u eller o.
  - **Två tips samtidigt:** bara det första som passar visas.
  - **Länk:** tipsraden har länken "📖 Så läser du romaji".
  - **Befintliga tips** för shi, chi, tsu, fu och wo finns kvar.
- **Lika tecken i Öva:**
  - **Var:** en tredje nivå bredvid "Tecken" och "Enkla ord".
  - **Fråga:** "Vilket tecken är shi?". Barnet väljer mellan tecknen i ett förväxlingspar, och ljudet spelas upp.
  - **Vilka par:** bara par där barnet redan har sett alla tecken.
  - **Om inget par finns:** beskedet "Lär dig fler tecken först".
- **Dold romaji:** i ordövningen visas romajin under ordet först när barnet har svarat.

## Romaji-guiden: "Så läser du romaji"

> Romaji är japanska ljud skrivna med våra bokstäver. Men japanska läses inte som svenska! De här bokstäverna är knepigast:

| Romaji | Säg så här | Inte så här |
|---|---|---|
| **u** (う) | som o i *bo*, men utan att runda läpparna | inte som u i *hus* |
| **o** (お) | som å i *båt* | inte som o i *ko* |
| **ki, ke** | alltid hårt k, som i *kaka* | inte "tji" som i *kind* |
| **gi, ge** | alltid hårt g, som i *gata* | inte "ji" som i *ge* |
| **ya, yu, yo** | y låter som svenskt j: *ja*, *ju*, *jå* | inte som y i *yxa* |
| **ji, ja, ju, jo** | som j i engelska *jeans*: "dji" | inte som j i *ja* |
| **shi, sha** | som tj-ljudet i *tjugo* | inte som sj i *sjö* |
| **chi, cha** | som i engelska *chips* | |
| **tsu** | ts som i *katts* | |
| **z** | ett surrande s, som ett bi: zzz | inte som ett vanligt s |
| **r** | en lätt studs med tungan, mitt emellan r och l | inte ett rullande r |
| **fu** | blås lätt mellan läpparna | inte ett hårt f |
| **w** | som w i engelska *water* | inte som v |
| **aa, ii, uu, ee, ou** | håll ljudet dubbelt så länge | |
| **kk, tt, pp, ss** | gör en kort paus innan | |

> Tips: Tryck på 🔊 och härma. Ljudet är alltid rätt, även när bokstäverna lurar dig!

## Uttalstips på korten

Tipsen väljs utifrån kortets romaji, och det första som passar visas:

| Om romajin … | Tipsrad |
|---|---|
| finns i den befintliga tipslistan (shi, chi, tsu, fu, wo) | befintligt tips, oförändrat |
| börjar på **k** följt av **i** eller **e**, eller är **ky-** | "Hårt k som i *kaka* – inte 'tji'." |
| börjar på **g** följt av **i** eller **e**, eller är **gy-** | "Hårt g som i *gata* – inte 'ji'." |
| börjar på **y** | "y låter som svenskt j." |
| börjar på **j** | "Som j i engelska *jeans*: 'dji'." |
| börjar på **z** | "Surrande s, som ett bi: zzz." |
| börjar på **r** | "En lätt studs med tungan, mitt emellan r och l." |
| är **u** | "Som o i *bo*, men utan runda läppar." |
| är **o** | "Som å i *båt*." |

## Förväxlingspar i "Lika tecken"

| Par | Varför de förväxlas |
|---|---|
| シ / ツ | prickarnas placering och strecken i olika riktning |
| ソ / ン | strecken nedåt (ソ) eller uppåt (ン) |
| ぬ / め | ぬ har en ögla, め har det inte |
| ね / れ / わ | samma vänsterdel, olika slut |
| る / ろ | ögla eller inte |
| は / ほ | ett extra streck |
| さ / ち | spegelvända |
| き / さ | ett extra streck |
| い / り | två streck med olika längd |
| ク / タ | ett extra streck |
| ウ / ワ | pricken överst |

## Teknik (kort)

- **Data:** minnesknepen, förväxlingsparen och guidetexterna läggs i `src/curriculum.js` (`mnemonics`, `lookAlikes`, `romajiGuide`). `MNEMONIC_OVERRIDES` i `main.js` tas bort.
- **Datatester:**
  - alla 92 grundtecken har ett minnesknep
  - varje par innehåller bara tecken som finns i kursplanen
  - varje uttalsregel matchar minst ett tecken.
- **Beteendetester:**
  - guidesidan nås från startsidan
  - tipsraden och länken visas på rätt kort
  - "Lika tecken" frågar bara om sedda par och har rätt svar bland alternativen
  - romajin döljs tills barnet har svarat.
